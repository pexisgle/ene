# `ene-tool-common`

> `ToolAction` trait, shared helpers, and the standard prelude for Ene tool binaries.

`ene-tool-common` is the primary dependency for any tool binary in the `tools/` workspace. It provides:

- The **`ToolAction`** and **`ToolSpecArgs`** traits that every tool action must implement.
- A **`prelude`** module re-exporting everything a tool author needs in one `use` statement.
- HTML-to-Markdown utilities for web-content tools.
- Re-exports of text truncation utilities from `ene-common`.

See also: [`ene-tool-derive`](ene-tool-derive.md) for the proc-macros that implement these traits automatically, and [`ene-tool-proto`](ene-tool-proto.md) for the underlying wire types.

---

## `ToolSpecArgs` trait

A static-dispatch interface for types that describe a tool's metadata. Implemented automatically by `#[derive(ToolSpec)]` and `#[derive(ToolAction)]`.

```rust
pub trait ToolSpecArgs {
    /// The canonical tool name in `namespace.action` form.
    const TOOL_NAME: &'static str;

    /// The human-readable display name (set via `#[tool(display_name = "…")]`).
    const DISPLAY_NAME: &'static str;

    /// A one-sentence summary of what the tool does.
    const SUMMARY: &'static str;

    /// Builds and returns the full [`ToolSpec`] for this action.
    fn spec() -> ToolSpec;
}
```

You rarely need to call these constants directly; they are consumed internally by the `ToolAction` implementation and by `run_tool_server`.

## `ToolAction` trait

The core trait implemented by every executable tool action.

```rust
pub trait ToolAction: ToolSpecArgs + Send + Sync {
    /// The tool's canonical name. Matches `Self::TOOL_NAME`.
    fn name(&self) -> &'static str;

    /// Returns the full [`ToolSpec`] for this action.
    fn definition(&self) -> ToolSpec;

    /// Execute the action with the given JSON-encoded argument string.
    ///
    /// `arguments` is the raw JSON object passed by the LLM. Implementations
    /// created with `#[derive(ToolAction)]` deserialize this automatically.
    fn execute(&self, arguments: &str) -> Result<String, ToolError>;
}
```

When using `#[derive(ToolAction)]`, the `execute` method is generated by the macro. You only need to implement the `async fn run(&self) -> Result<String, ToolError>` method on your struct.

## `prelude` module

Import everything you need in one line:

```rust
use ene_tool_common::prelude::*;
```

This re-exports:

| Item | Source |
|---|---|
| `async_trait` | `async-trait` crate (attribute macro) |
| `ToolAction` | This crate |
| `ToolSpec` | `ene-tool-proto` |
| `tool_action` | `ene-tool-derive` attribute macro |
| `ToolError` | `ene-tool-proto` |
| `JsonSchema` | `schemars` derive macro |
| `Deserialize` | `serde` derive macro |

> [!NOTE]
> All re-exports from other workspace crates are annotated with `#[doc(no_inline)]` so that rustdoc links resolve to the original crate's documentation.

## `truncate` module

Re-exports text truncation utilities from `ene-common` for use in tool output formatting.

```rust
pub use ene_common::truncate::{Truncate, TruncateResult};
```

### `Truncate` trait

Implemented on `String` and `&str`. Provides:

```rust
pub trait Truncate {
    /// Truncate to at most `max_chars` Unicode scalar values.
    /// Returns a `TruncateResult` indicating whether truncation occurred.
    fn truncate_chars(&self, max_chars: usize) -> TruncateResult<'_>;
}
```

### `TruncateResult`

```rust
pub struct TruncateResult<'a> {
    pub content: &'a str,
    /// True if the original string was longer than max_chars.
    pub was_truncated: bool,
}
```

Typical usage in a tool:

```rust
let output = large_text.truncate_chars(8_000);
if output.was_truncated {
    Ok(format!("{}\n\n[Output truncated]", output.content))
} else {
    Ok(output.content.to_string())
}
```

## `html` module

HTML-to-Markdown conversion and content extraction for tools that fetch web content.

> [!NOTE]
> This module is built on the [`scraper`](https://crates.io/crates/scraper) crate and performs static HTML parsing — it does not execute JavaScript.

### Functions

```rust
/// Convert an HTML string to Markdown.
///
/// Strips navigation, ads, and boilerplate; extracts the main article body.
pub fn html_to_markdown(html: &str) -> String;

/// Extract plain text from an HTML string (no Markdown formatting).
pub fn html_to_text(html: &str) -> String;

/// Extract the `<title>` from an HTML document, if present.
pub fn extract_title(html: &str) -> Option<String>;
```

### Example

```rust
use ene_tool_common::html;

let html = reqwest::get("https://example.com").await?.text().await?;
let title = html::extract_title(&html).unwrap_or_default();
let markdown = html::html_to_markdown(&html);

Ok(format!("# {title}\n\n{markdown}"))
```

## Wiring a tool binary

After implementing `ToolAction` (manually or via derive), wire it into a server loop using `run_tool_server` from `ene-tool-proto`:

```rust
// tools/my_tool/src/main.rs
use ene_tool_common::prelude::*;
use ene_tool_proto::run_tool_server;

mod actions;
use actions::MyAction;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    run_tool_server::<MyAction>().await
}
```

`run_tool_server` handles the full IPC lifecycle: handshake, initialize, list-tools, and dispatch loop. See [`ene-tool-proto`](ene-tool-proto.md) for details.
