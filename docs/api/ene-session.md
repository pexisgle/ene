# Session APIs — absorbed into `ene-mind`

> **Status:** The standalone session crate was removed.
> Session types now live under [`ene-mind`](ene-mind.md) (`ene_mind::session` and crate-root re-exports).

Import session APIs from `ene_mind`:

```rust
use ene_mind::{ConversationSession, SessionConfig, SessionId, SplitReason};
```

See also the English/Japanese mind API docs and [API v2](../architecture/api-v2.md).
