# `ene-desktop` ユーザーガイド

`ene-desktop` は、リアルタイム 3D VRM アバター描画 (`ene-vrm`)、ローカル音声合成・認識 (`ene-voice`)、およびライブ感情・演出表現を備えた GUI デスクトップアプリケーションです。

---

## デスクトップアプリの起動

```bash
# デスクトップアプリの起動
cargo run -p ene-desktop
```

---

## 主な機能

- **VRM 3D アバターウィンドウ**: `wgpu` ハードウェアアクセラレーションを使用した VRM 1.0 モデルの表示。
- **リップシンク & 表情アニメーション**: `ene-mind` から `Performance` イベントを受信し、表情ブレンドシェイプ (Happy, Angry, Surprised) や口パク Viseme (あ, い, う, え, お) をアニメーション再生。
- **ローカル音声パイプライン**: Silero VAD / Whisper STT によるリアルタイムマイク入力と音声合成出力のサポート。
- **最前面表示・透過ウィンドウ**: デスクトップ上に常駐するキャラクター体験のためのオーバーレイ表示モード。
- **キャラクターカードエディター**: ビジュアルな `CCv3` 編集（アイデンティティ、性格、シナリオ、挨拶、記憶補正指示、ロアブック、モーションカタログ）に加え、スキーマ・アセット検証、バックアップ付きアトミック保存、破棄確認を備えています。詳しくは[キャラクターカードエディターガイド](../guide/character-card-editor.md)を参照してください。

## Spotlight クイックランチャー (Alt+Space)

どのアプリケーションからでも `Alt+Space` を押すと、Spotlight コマンドパレットが開きます。アバターウィンドウにフォーカスを移すことなく操作できる、半透明の最前面入力バーです。

- **設定を開く** — AI 設定ページに移動します。
- **チャットを開く** — 専用チャットウィンドウを開きます。
- **マイクを切り替え** — 音声収録を開始/停止します。
- **キャプションオーバーレイを切り替え** — フローティングキャプションウィンドウを表示/非表示にします。
- **自由入力** — コマンドに一致しないテキストを Enter で送信すると、チャット入力と同じ経路で Ene に送信されます。

パレットは **設定 → アクセシビリティ** で制御します。「スポットライトを有効化 (Alt+Space)」でグローバルショートカットをオン/オフ、「フローティングキャプションオーバーレイを有効化」でキャプションウィンドウを制御します。

### プラットフォーム上の制限

- **Wayland**: `global-hotkey` クレートに Wayland バックエンドがないため、グローバルショートカットとして登録されるのは X11 と Windows のみです。Wayland では Ene にフォーカスがあるときに `Alt+Space` でパレットが開きます（アプリ内フォールバック）。
- **Windows**: `Alt+Space` は OS のウィンドウメニューショートカットです。グローバル登録が有効な間、Ene がシステム全体でこのキーを消費します。

## フローティングキャプションオーバーレイ

フローティングキャプションオーバーレイは、アシスタントの発話をリアルタイムでタイプライター風に表示する独立した半透明の字幕ウィンドウです。Spotlight の「キャプションオーバーレイを切り替え」または 設定 → アクセシビリティ から開きます。

- **ドラッグ** — タイトルバーを掴んで画面上の好きな場所へ移動できます。位置は記憶されます。
- **ピン留め / ピン解除** — ウィンドウを他のアプリより前面に維持します（ウィンドウレベルを設定できない Wayland では無効）。
- **演出キュー** — 発話中、最新のキューの名前（例: `happy`）が小さなタグとして表示されます。
- **閉じる** — ✕ ボタンでオーバーレイを非表示にします。キャプションフィードは次のターンまで動作し続けます。
