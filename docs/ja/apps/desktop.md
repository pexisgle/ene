# デスクトップユーザーガイド

`ene-desktop` は GUI アプリケーションです。3D VRM アバター・チャットペイン・
音声入出力・オーバーレイ/字幕・システムトレイ・設定 UI を備えます。

```sh
cargo run -p ene-desktop [vrm-path] [vrma-path]
```

2 つの位置引数で、キャラクターの VRM モデルとデフォルト VRMA モーション
クリップを上書きできます。

## メインウィンドウ

- **3D アバター** — 読み込まれた VRM キャラクター。表情・モーション・視線
  追従・spring bone・シーン物理（モデルをドラッグできます）。
- **チャットペイン** — キャラクターとの会話。権限プロンプトとツールの
  質問がインライン表示されます。
- **字幕オーバーレイ** — キャラクターの発話を画面上に字幕表示
  （`desktop.caption_enabled`）。
- **スポットライト** — クイックアクセス用のグローバルオーバーレイ
  （`desktop.spotlight_enabled`）。

## 音声

`voice` フィーチャー（デフォルト）で、アプリはマイク音声をキャプチャし
（`desktop.mic_device`）、設定済み STT プロバイダーで文字起こしし、TTS で
応答をストリーミング再生し、その音声からアバターのリップシンクを駆動します。
設定 → 音声でプロバイダー・モデル・ボイス・速度を選択します。

## システムトレイとホットキー

- トレイメニューでキャラクターの状態を確認し、チャット/設定を開いたり
  終了したりできます。
- グローバルホットキーでチャット/スポットライトオーバーレイを開きます。

## 設定ページ

設定ウィンドウは論理 900 × 700 ピクセルで開き、520 × 560 まで縮小できます。
幅 720 ピクセル以上では、サイドバーが全ページを 4 分類で表示します。
サイドバー最上部の検索欄へ入力すると分類一覧がページ/セクションの順位付き
検索結果に置き換わり、セクションを選ぶと該当ページを開いてカードまで
スクロールし、ハイライトします。幅 720 ピクセル未満では、サイドバーの代わりに
分類付きページ選択と同じ検索 UI を表示し、設定コントロールは横スクロールせず
ラベルの下へ折り返します。

| 分類 | ページ |
|---|---|
| 基本 | キャラクター、キャラクターカード、表示、アクセシビリティ |
| AI・音声 | AI、音声、機能 |
| データ・アクセス | メモリ、メモリ台帳、セッション、権限、コネクタ |
| システム | デバッグ |

| ページ | 編集内容 |
|---|---|
| キャラクター | デフォルト表情/モーション・視線追従の強さ・位置・スケール |
| キャラクターカード | アクティブカードのフィールド編集（[キャラクターエディタ](../guides/character-editor.md)参照） |
| 表示 | 品質プリセット・UI 言語・外観テーマ |
| アクセシビリティ | スポットライト・字幕オーバーレイ |
| AI | プロバイダー・タスクモデル・リトライ/フォールバック・プロバイダー健全性 |
| 音声 | TTS・STT・マイク/VAD の選択と音声調整 |
| 機能 | 音声・プロアクティブ・mind・ツール機能の切り替え |
| メモリ | ブラウズ/検索/保留/約束のタブ |
| メモリ台帳 | 型付きメモリの完全レビュー: 編集・ピン留め・承認・却下 |
| セッション | セッションの一覧・検索・インポート・エクスポート・アーカイブ |
| 権限 | ツール権限の付与一覧・失効/リセット |
| コネクタ | 外部サービスアカウント（[コネクタ](../concepts/connectors.md)参照） |
| デバッグ | 診断とパイプライン詳細 |

### 外観

表示 → テーマは、設定・チャット・スポットライト・字幕・ネイティブウィンドウへ
適用されます。**システム**は OS の配色に追従し、**ライト**と**ダーク**は OS
変更より優先して即時反映されます。設定値とプラットフォーム別の挙動は
[`desktop.theme`](../configuration.md)を参照してください。

## プラットフォームメモ

- **Linux**（X11/Wayland）が対応プラットフォーム。Wayland では利用可能な
  場合に layer-shell オーバーレイを使用します。
- **Windows** は Linux からクロスコンパイルされます（flake の mingw
  ツールチェーン）。ネイティブ Windows 開発シェルはありません。
- **ヘッドレス CI** はソフトウェア Vulkan（lavapipe）で動作:
  `DISPLAY=:1 WGPU_BACKEND=vulkan`。
- 音声なしビルド: `cargo build -p ene-desktop --no-default-features`
  （voice モジュールは無機能スタブになります）。

## データの場所

設定・キャラクター・モデル・データベースはアセット/アプリデータディレクトリ
にあります — [設定](../configuration.md) 参照。
