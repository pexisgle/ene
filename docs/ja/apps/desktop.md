# デスクトップユーザーガイド

`ene-desktop` は GUI アプリケーションです。3D VRM アバター・チャットペイン・
音声入出力・オーバーレイ/字幕・システムトレイ・設定 UI を備えます。

```sh
cargo run -p ene-desktop [vrm-path] [vrma-path]
```

2 つの位置引数で、キャラクターの VRM モデルとデフォルト VRMA モーション
クリップを上書きできます。

## メインウィンドウ

- **3D アバター** — 読み込まれた VRM キャラクター。表情・モーション・視線
  追従・spring bone・シーン物理（モデルをドラッグできます）。
- **チャットペイン** — キャラクターとの会話。権限プロンプトとツールの
  質問がインライン表示されます。
- **字幕オーバーレイ** — キャラクターの発話を画面上に字幕表示
  （`desktop.caption_enabled`）。
- **スポットライト** — クイックアクセス用のグローバルオーバーレイ
  （`desktop.spotlight_enabled`）。

## 音声

`voice` フィーチャー（デフォルト）で、アプリはマイク音声をキャプチャし
（`desktop.mic_device`）、設定済み STT プロバイダーで文字起こしし、TTS で
応答をストリーミング再生し、その音声からアバターのリップシンクを駆動します。
設定 → 音声でプロバイダー・モデル・ボイス・速度を選択します。

## システムトレイとホットキー

- トレイメニューでキャラクターの状態を確認し、チャット/設定を開いたり
  終了したりできます。
- グローバルホットキーでチャット/スポットライトオーバーレイを開きます。

## 設定ページ

設定ウィンドウは論理 900 × 700 ピクセルで開き、520 × 560 まで縮小できます。
幅 720 ピクセル以上では、サイドバーが全ページを **設定**（日常的に調整する
項目）と **管理**（データ・アカウント・診断）の 2 分類で表示します。
サイドバー最上部の検索欄へ入力すると分類一覧がページ/セクションの順位付き
検索結果に置き換わり、セクションを選ぶと該当ページを開いてカードまで
スクロールし、ハイライトします。検索結果にはプラグイン名も含まれ、検索中は
隠れた詳細項目も自動表示されます。幅 720 ピクセル未満では、サイドバーの
代わりに分類付きページ選択と同じ検索 UI を表示し、設定コントロールは
横スクロールせずラベルの下へ折り返します。キーボード操作（Tab・矢印・
Enter）に対応し、長い日本語テキストも正しく表示されます。

| 分類 | ページ |
|---|---|
| 設定 | 概要、一般、キャラクターとユーザー、AI とモデル、音声とオーディオ、ふるまい、メモリと保存、セキュリティとダウンロード、プラグイン、詳細設定 |
| 管理 | キャラクターカードエディタ、メモリ、セッション、スケジュール、権限、コネクタ、診断 |

| ページ | 編集内容 |
|---|---|
| 概要 | 設定が必要な項目・障害・再起動待ち・必要な認証情報を一覧し、各ページへ誘導 |
| 一般 | 品質プリセット・UI 言語・外観テーマ・スポットライト・字幕・アクセシビリティ |
| キャラクターとユーザー | デフォルト表情/モーション・視線追従の強さ・位置・スケール・ユーザー名 |
| キャラクターカードエディタ | アクティブカードのフィールド編集（[キャラクターエディタ](../guides/character-editor.md)参照） |
| AI とモデル | プロバイダー・タスクモデル・リトライ/フォールバック・プロバイダー健全性・API キー（マスク表示） |
| 音声とオーディオ | TTS・STT・マイク/VAD の選択と音声調整 |
| ふるまい | 音声・プロアクティブ・mind・ツール機能の切り替え |
| メモリと保存 | メモリの有効化・承認ワークフロー・保持制限・ストア整合性 |
| メモリ | ブラウズ/検索/保留/約束のタブと、型付きメモリ台帳（編集・ピン留め・承認・却下） |
| スケジュール | 定期実行ツールの作成・有効化・削除・実行履歴 |
| プラグイン | プラグインセンター: 検出済み/設定済み/MCP、スキーマ駆動の設定とプロファイル、認証情報、セキュリティ、動的オプション、検証 |
| 詳細設定 | 専用 UI のない `settings.json` の全項目（検索可能・スキーマ駆動） |
| セッション | セッションの一覧・検索・インポート・エクスポート・アーカイブ |
| 権限 | ツール権限の付与一覧・失効/リセット |
| コネクタ | 外部サービスアカウント（[コネクタ](../concepts/connectors.md)参照） |
| 診断 | ランタイム/AI/音声/プラグインの健全性・パイプライン詳細・デバッグオーバーレイ |

ローカルモデル設定はプラグインプロファイルに一元化されています。AI ページは
`plugins.list.local-llm` / `llama-server` のプロファイルをモデル候補として
表示し、`ai.local_models` は適用時にプロファイルから自動導出されるため、
二重編集は不要です。スケジュールページは cron / 間隔 / JSON を送信前に検証し、
ホストのタイムゾーンを既定値として使い、保留中の実行確認を直接承認・拒否できます。

### 下書き適用パイプライン

各ページは `settings.json` を直接書き換えません。編集は下書きに蓄積され、
変更パス・単調増加のリビジョン・フィールドごとのスキーマ検証・秘密情報の
状態が追跡されます。ウィンドウ下部の「未適用の変更」バーから適用/破棄を
行います。適用は非同期で実行され、秘密情報をマージした下書きを登録
スキーマと各 dirty プラグイン自身の `ValidateConfig` の両方で検証 → 原子的に
保存 → ランタイムアクターへ反映し、実際の影響（即時 / ホットリロード /
プラグイン再起動 / アプリ再起動）を結果バナーに表示します。古いリビジョンに
基づく下書きは競合として拒否され、ランタイム適用が失敗した場合は保存済み
設定をロールバックします。保存済みの秘密情報（API キー、プラグインの
config/profiles/credentials、MCP 認証ヘッダ）は UI 状態に保持されず、下書きは
redacted プレースホルダのみを持ち、適用時にストアからマージされます。
プラグインセンターにはホスト側で redact されたスナップショットが届きます。
各画面の一覧・検索・状態取得はブリッジランタイム上で非同期実行され、
描画スレッドは IPC でブロックされません。

### プラグインセンター

プラグイン・MCP サーバー・検出済みだが未設定のバイナリが 1 か所に表示され
ます。各プラグインカードは健全性・種類・機能・マニフェスト情報・有効
セキュリティ（承認モード・緊急停止・FS グラント・サンドボックス・DB クォータ）
を表示し、設定とプロファイルはプラグイン自身の JSON Schema で編集します
（型付きコントロール + raw JSON フォールバック、未知キーは保持）。
動的設定に対応するプラグインは「オプション取得」ボタン、「設定を検証」ボタンは
プラグイン自身のバリデーターを実行します。`x-ene-ui` メタデータ
（group/order/control/advanced/impact/options_path）と
`x-ene-profiles-schema` がフォームを駆動します。

### 外観

表示 → テーマは、設定・チャット・スポットライト・字幕・ネイティブウィンドウへ
適用されます。**システム**は OS の配色に追従し、**ライト**と**ダーク**は OS
変更より優先して即時反映されます。設定値とプラットフォーム別の挙動は
[`desktop.theme`](../configuration.md)を参照してください。

## プラットフォームメモ

- **Linux**（X11/Wayland）が対応プラットフォーム。Wayland では利用可能な
  場合に layer-shell オーバーレイを使用します。
- **Windows** は Linux からクロスコンパイルされます（flake の mingw
  ツールチェーン）。ネイティブ Windows 開発シェルはありません。
- **ヘッドレス CI** はソフトウェア Vulkan（lavapipe）で動作:
  `DISPLAY=:1 WGPU_BACKEND=vulkan`。
- 音声なしビルド: `cargo build -p ene-desktop --no-default-features`
  （voice モジュールは無機能スタブになります）。

## データの場所

設定・キャラクター・モデル・データベースはアセット/アプリデータディレクトリ
にあります — [設定](../configuration.md) 参照。
