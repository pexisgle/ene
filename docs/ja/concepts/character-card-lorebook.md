# キャラクターカード・ロアブック

CCv3 キャラクターカードには **ロアブック**（`character_book`）— トリガーとなる
`keys`・`content`・任意フラグを持つワールド情報エントリの集合 — を同梱できます。
このページでは、Ene がロアブックエントリをどうマッチさせ、CCv3 の `@@`
デコレータをどう解釈するかを説明します。

## エントリのマッチング

エントリは次の条件で選択されます:

- `constant: true`（常に選択）**または**
- `keys` の少なくとも 1 つが直近の会話（`scan_depth` 以内）にマッチし、
  `@@exclude_keys` のどの値にもマッチしない;
- `selective` / `secondary_keys` は CCv3 仕様どおり:
  `selective` 指定時は `secondary_keys` の少なくとも 1 つもマッチする必要があります;
- 有効な `@@` デコレータの条件がすべて満たされている（下記参照）。

マッチングは部分文字列一致で、デフォルトでは **大文字小文字を区別しません**
（`case_sensitive: true` で区別します）。日本語など空白区切りでない言語のキーも
部分文字列一致で動作するため、`ドラゴン` は `ドラゴンが現れた` にマッチします。
`use_regex: true` の場合、キーは正規表現として扱われ、コンパイルできないキーを
持つエントリは決してマッチしません。

> `@@additional_keys` について: 仕様は「これらの値のうち少なくとも 1 つが
> 存在すること」と定義しています — メインの `keys` に積み重ねる AND 条件であり、
> 「全てがマッチしなければならない」わけではありません。Ene は仕様に従います。

## 注入

デコレータ行は、コンテンツを保存・注入する前に `content` から除去されます。
生の `@@…` テキストがプロンプトに漏れることはありません。

キー一致・constant エントリはハイブリッド想起のマージ経路で想起結果に加算されます。
配置制御（`@@depth`・`@@position`・`@@role`・`token_budget`・専用プロンプト
セクションとしての保証注入）はまだ配線されていません — エントリは想起ブロックに
のみ入り、デコレータはパース・除去のみ行われます。

## デコレータ一覧

デコレータは `content` の先頭行に配置します（コンテンツ内のどこでも機能し、
注入前に除去されます）。

### 発火制御

| デコレータ | Ene の挙動 |
|---|---|
| `@@activate_only_after N` | チャットログ全体のアシスタント（キャラクター）メッセージ数が `N` に達するまでマッチしない。カウントは直近ターンのウィンドウではなくログ全体を対象とします。`N = 0` はゲート無効。 |
| `@@activate_only_every N` | チャットログのアシスタントメッセージ数が `N` で割り切れるときのみマッチ。`N <= 1` はゲート無効。 |
| `@@keep_activate_after_match` | 一度マッチしたら以後常にマッチ（スティッキー）。 |
| `@@dont_activate_after_match` | 一度マッチしたら以後マッチしない。 |
| `@@activate` | 無条件でマッチさせる（`@@dont_activate` とキーフィルタを上書き）。 |
| `@@dont_activate` | マッチさせない（`@@activate` がなければ）。 |

スティッキーデコレータ（`keep_activate_after_match` /
`dont_activate_after_match`）は過去のマッチ状態を必要としますが、想起マージ経路には
その状態がありません。仕様では過去のマッチが不明な場合にこのデコレータを無視して
よいとされているため、この経路では不活性です。セッション状態を保持する予定の
注入パイプラインはまだ配線されていません。

### 配置

| デコレータ | Ene の挙動 |
|---|---|
| `@@depth N` | パースのみ — メッセージ深さ注入は未配線。`N < 1` はプリフィルを意味しますが、Ene はプリフィル非対応のため高優先度位置にフォールバックします。 |
| `@@reverse_depth N` | パースのみ — 古い方から数えます（メッセージ深さ注入は未配線）。 |
| `@@instruct_depth N` | **無視** — Ene はチャットベースであり、仕様はチャット文脈でこのデコレータを無視するとしています。続く `@@@` フォールバック行が参照されます。 |
| `@@position after_desc\|before_desc\|personality\|scenario` | パースのみ — 意味的セクション配置は未配線。 |

### スキャン

| デコレータ | Ene の挙動 |
|---|---|
| `@@scan_depth N` | このエントリに限りロアブックの `scan_depth` を上書き。`recursive_scanning` 時は、他のエントリのコンテンツが上書きに関係なくマッチに使われます（仕様どおり）。 |
| `@@instruct_scan_depth N` | **無視** — チャット文脈（`@@instruct_depth` 参照）。`@@@` フォールバック参照。 |
| `@@is_greeting N` | **無視** — Ene はアクティブなグリーティング番号を追跡していません。仕様は判定不能な場合に無視を許容しています。`@@@` フォールバック参照。 |

### フィルタ

| デコレータ | Ene の挙動 |
|---|---|
| `@@additional_keys A,B,…` | 値のうち少なくとも 1 つがスキャン窓に現れる必要がある（`keys` に積む AND 条件）。複数回指定可能。`use_regex` に従います。 |
| `@@exclude_keys X,Y,…` | いずれかの値が現れたらエントリを抑制。`use_regex: true` の場合は無視（仕様どおり）。NOT ロジックはこのデコレータに統合されました — Ene 独自の `not_keys` カードフィールドは削除済みです。 |
| `@@is_user_icon name` | **無視** — Ene にユーザーアイコンのプロンプト機能はありません。`@@@` フォールバック参照。 |

### メタ

| デコレータ | Ene の挙動 |
|---|---|
| `@@role assistant\|system\|user` | パースのみ — メッセージ深さ注入の実装時に適用。 |
| `@@ignore_on_max_context` | パースのみ — 注入実装時にトークン予算パスで消費予定。 |
| `@@disable_ui_prompt post_history_instructions\|system_prompt` | **無視** — 有効化するとカードが Ene の感情表現出力契約を無効化できてしまうためです（コアの製品保証）。`@@@` フォールバック参照。 |

## フォールバックチェーン（`@@@`）

未知・不正・文脈により無視されるデコレータはスキップされますが、直後の
**フォールバック**（`@@@name` 行）が代わりに上から順に検討されます
（仕様の「認識されない、または無視されるデコレータ」ルール）。チェーンは任意の
長さにできます:

```
@@risu_only_decorator 4
@@@agn_only_decorator 4
@@@activate_only_after 4
```

チェーン内のどの要素も認識できなければ、グループ全体が無視されます
（コンテンツからは除去されます）。同名デコレータは**最初の 1 つだけ**が有効です —
ただし仕様で複数回の使用が許されている `@@additional_keys` を除きます。
