# キャラクターカードマクロ (CBS)

キャラクターカード (CCv3) には **CBS テンプレートマクロ** を埋め込めます。これは
Ene がカードをプロンプトへコンパイルする際に展開される `{{…}}` プレースホルダで、
カード作者がキャラクター名・ユーザー名を参照したり、カードのフィールドを挿入したり、
特性を変化させたり、時間帯に反応したりできます。値のハードコードは不要です。

展開は **Identity Kernel のコンパイル時**（ターンごとに 1 回）に走ります。
したがってマクロの出力はそのターンのプロンプトに固定されます。

---

## 対応マクロ

| マクロ | 展開結果 | 備考 |
|---|---|---|
| `{{char}}`, `<char>`, `<bot>` | キャラクター表示名 | `nickname` が設定されていれば `name` より優先 |
| `{{user}}` | ユーザー表示名 | |
| `{{user_persona}}` | 構造化ユーザーペルソナブロック | 名前 / 説明 / 関係 / 代名詞 / メモ。ペルソナ未設定時は除去 |
| `{{description}}` | カードの `description` フィールド | |
| `{{personality}}` | カードの `personality` フィールド | |
| `{{scenario}}` | カードの `scenario` フィールド | |
| `{{persona}}` | カードの `creator_notes` フィールド | |
| `{{mesExamples}}` | カードの `mes_example` フィールド | |
| `{{random:a,b,c}}` | いずれか 1 つをランダム選択 | **評価のたびに再抽選** |
| `{{pick:a,b,c}}` | いずれか 1 つを安定選択 | **チャット内で安定** — 後述 |
| `{{roll:d20}}` | `1..=N` のダイスロール | `d` 接頭辞は任意。評価ごとに再抽選 |
| `{{time}}` | 現地時刻 `HH:MM` | |
| `{{date}}` | 現地日付 `YYYY/MM/DD` | |
| `{{isotime}}` | 現地時刻 `HH:MM:SS` | |
| `{{isodate}}` | 現地日付 `YYYY-MM-DD` | |
| `{{weekday}}` | 英語の曜日名 | 例: `Saturday` |
| `{{idle_duration}}` | 人間向けのアイドル経過 | 例: `just now`, `45 minutes`, `3 hours`, `2 days` |
| `{{// …}}`, `{{comment:…}}` | *(除去)* | 作者向けコメント。プロンプトから取り除かれる |
| `{{reverse:text}}` | `text` の逆順 | |

---

## `{{random}}` と `{{pick}}` の違い

2 つの選択マクロは見た目が似ていますが、CBS エコシステムの仕様どおり挙動が異なります。

- **`{{random:a,b,c}}`** は評価の**たびに**新しい選択肢を抽選します。
  ターンごとに変化させたい演出に使います。
- **`{{pick:a,b,c}}`** はチャットの存続期間中**安定した**選択肢に解決されます。
  選択肢のテキストとセッションごとのシード（キャラクター + セッション ID）から
  決定的に導かれるため、一度決まった特性（髪の色、出身地、好きな食べ物など）は、
  後続ターンで Identity Kernel が再コンパイルされても**変わりません**。

Identity Kernel は毎ターン再コンパイルされるため、`{{pick}}` をランダム扱いする
（従来の挙動）とキャラクター設定がターンごとに揺れていました。`{{pick}}` は
シード化され、同じチャットでは常に同じ選択肢になります。別のチャット（別のセッション）
では異なる選択になり得ます。

## 時刻系マクロ

時刻系マクロはコンパイル時の**現地**システム時計に対して展開されます。

- `{{time}}` / `{{isotime}}` — 時刻。
- `{{date}}` / `{{isodate}}` — 日付。
- `{{weekday}}` — 英語の曜日名。
- `{{idle_duration}}` — ユーザーの最終活動からの経過を、粗く人間向けに表現
  （`just now`, `N minutes`, `N hours`, `N days`）。活動記録がない場合は、
  誤解を招くゼロを表示せず、マクロを未展開のまま残します。

これにより、朝は挨拶を変える、長い沈黙の後に反応する、といった時間帯依存の
カード記述が可能になります。

---

## 未実装

一部の CBS 方言にある制御構文マクロ（RisuAI 風の `{{#if}}`、算術、条件分岐）は
意図的に**サポートしていません**。未知のマクロはテキスト中にそのまま残るため、
タイプミスは消えずに目に見える形で表面化します。
