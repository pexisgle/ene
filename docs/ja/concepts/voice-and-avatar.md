# 音声とアバター

## 音声パイプライン

音声パイプラインは 3 段階で、各段階がプロバイダープラグインに支えられています:

| 段階 | 同梱プロバイダー | 設定 |
|---|---|---|
| **STT**（音声 → テキスト） | `whisper`（ローカル whisper.cpp） | `ai.stt.provider` |
| **TTS**（テキスト → 音声） | `kokoro`（ローカル ONNX）・`edge-tts`・`elevenlabs`・`openai-tts`・`voicevox` | `ai.tts.provider` |
| **VAD**（音声区間検出） | `onnx`（Silero）・`none` | `ai.vad.provider` |

`ai.tts` / `ai.stt` はプロバイダー選択のみ行います。プロバイダー固有の値
（`model`・`voice`・`speed`・`language`・モデルパス・エンジンモード）は
`plugins.list.<provider>.config` に置かれ、各プロバイダープラグインが公開する
スキーマを音声設定ページが描画します。例えば Kokoro の音声は
`plugins.list.kokoro.config.voice`、VOICEVOX の話者は
`plugins.list.voicevox.config.speaker_id` です（managed エンジンは
`mode` / `server_path` を使用）。

デスクトップアプリはマイク音声（cpal）をキャプチャし、選択した STT
プロバイダーで文字起こしし、ランタイムの音声チャネルでストリーミングされて
くる TTS 音声チャンクを再生します（rodio）。音声プロバイダーは LLM
プロバイダーと同じプラグインホストレジストリ経由で解決されます。

音声はアバターにリアルタイムで反映されます:

- **Viseme** — 音声が口形ウェイトに分析され、リップシンクされます。
- **感情** — 現在の感情状態が表情（笑顔・驚き・…）を選びます。
- **ビート同期** — ビート同期デバイス設定時、アバターモーションが音楽の
  BPM に合わせて脈動します。

## パフォーマンスキュー

ターン中、mind の出力仲裁者が**パフォーマンスキュー**を発行します:

| キューの種類 | 意味 |
|---|---|
| `expression` | 表示するブレンドシェイプ表情 |
| `motion` | 再生するモーションクリップ（レイヤー+強度付き） |
| `lookat` | アバターが向くべき方向 |
| `cancel` | 現在のパフォーマンスを停止 |

各キューは source（`affect` — 感情エンジン由来、または `llm` — モデルが
要求）を持ちます。キューは提示前に検証され（表情はモデルに存在し、モーション
はカタログに存在する）、レート制限/ヒステリシス制御によりアバターが状態間で
ちらつきません。

## アバター（VRM）

デスクトップアプリは `ene-vrm`（独立した wgpu レンダラー）で
**VRM 1.0** モデルを描画します:

- **モデル読み込み** — カードの `assets`（または CLI 引数）の `.vrm`
  ファイル。ヒューマノイドボーン・表情・spring bone・ノード制約・視線・
  MToon マテリアルを含みます。
- **モーション** — VRMA アニメーションクリップ（待機・手を振る・…）を
  ブレンドレイヤーとリターゲットで再生。
- **表情** — VRM ブレンドシェイプを手続き的オーバーライド（まばたき・
  視線・口）と合成。
- **視線追従** — 設定範囲内でアバターがカーソルを追います。
- **Spring bone と物理** — 髪/服のシミュレーションと、ドラッグ操作のための
  シーン物理。

対応レンダリング API は [ene-vrm API リファレンス](../reference/api/ene-vrm.md) に
あります。

## デスクトップの音声/アバター設定

- 設定 → 音声: TTS/STT/VAD の選択・モデル/ボイス選択・速度。
- 設定 → グラフィック: 品質プリセット（描画解像度に影響）。
- 設定 → キャラクター: デフォルト表情/モーション・視線追従の強さ・位置・
  スケール。
- `desktop.caption_enabled` — 発話行の字幕オーバーレイ。
  `desktop.beat_sync` — ビート同期モーション用の音楽入力。

ネイティブ音声スタックなしでのビルドは `--no-default-features`
（voice 無効。audio モジュールは無機能スタブにコンパイル）で可能です。
