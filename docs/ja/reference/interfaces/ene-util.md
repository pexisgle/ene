# `ene-util` インターフェース

## 役割

フィーチャーゲート付きの重い依存を持つ純粋ユーティリティ関数。クレートの
規律: **I/O なし・ビジネスロジックなし・状態なし**。それ以外はドメイン
クレートに置きます。

## 公開モジュール

| モジュール | ゲート | 内容 |
|---|---|---|
| `truncate` | `truncate`（デフォルト） | `Truncate`・`TruncateResult` — 文字/行/末尾によるスマートな文字列切り詰め |
| `html` | `html` | `html_to_markdown`・`extract_html`・`extract_markdown` |

## 依存関係

- 依存: 内部なし（重い依存はフィーチャーゲート: htmd・scraper・ego-tree・
  regex）。
- 利用: `ene-mind`・`ene-runtime`・`ene-cli`・`ene-desktop`。

## リファクタリングの注目点

- 純粋性ルールはレビューで強制されます。I/O やドメイン知識が生えたヘルパー
  は移動先が必要です（例: 所有ドメインクレートへ）。
- フィーチャーゲートがデフォルトビルドを軽く保ちます。重い依存の追加は新しい
  フィーチャーの背後がパターンであり、無条件の依存追加ではありません。
