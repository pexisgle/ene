# IPCワイヤープロトコル & サンドボックスデータ仕様 (`ene-tool-proto`)

`ene-tool-proto` クレートは、ホスト（`ene-runtime` / アクター）と独立したツールプロセス間の通信用プロトコル（Wire Protocol）、データ転送トランスポート、およびサンドボックス制限パラメータのデータ構造を定義します。

---

## 1. メッセージフレームプロトコル

### 1. 長さプレフィックス付き JSON (Length-Prefixed JSON)
通信ソケット上を流れるメッセージは、以下のフレーム構造で直列化されます。
*   **ヘッダー**: 4バイトの大端エンディアン（Big-Endian）の符号なし32ビット整数（`u32`）。メッセージボディのバイト長を示します。
*   **ボディ**: UTF-8 でエンコードされた JSON 文字列。
*   **サイズ上限**: 悪意あるデータ注入やバッファオーバーフローを防止するため、1メッセージあたりの最大サイズは **64MB** (`MAX_MESSAGE_SIZE`) に制限されています。これを超えるフレームを受信した場合は即座にエラーとして接続を切断します。

---

## 2. IPC リクエスト & レスポンス (`IpcRequest` / `IpcResponse`)

### 1. `IpcRequest` (アクター → ツール)
*   **`Handshake`**: バージョンネゴシエーションおよびサンドボックスデータ・個別設定の転送。
*   **`ListTools`**: ツールが提供する全アクション定義（`ToolSpec`）の要求。
*   **`ListRagProfiles`**: RAG（ツール回収）用インデックス用メタデータの要求。
*   **`CallTool`**: ツール関数の実行要求。ツール名 `name` と引数 JSON 文字列 `arguments` を含みます。
*   **`SetCallContext`**: セッションIDとターンIDの通知。ツール側で会話別キャッシュやUndoチェックポイントを作るための文脈データ。
*   **`Shutdown`**: ツールの安全な終了要求。

### 2. `IpcResponse` (ツール → アクター)
*   **`HandshakeAck`**: ハンドシェイク確認。合意されたプロトコルバージョンを返します。
*   **`Tools`**: ツール定義のリストを返します。
*   **`RagProfiles`**: RAG用プロファイル一覧を返します。
*   **`CallResult`**: ツール実行結果。成功時は `Ok(String)`、失敗時は `Err(ToolError)`。

---

## 3. サンドボックス構成データ (`SandboxConfigData`)

ツールプロセスの権限を管理する設定定義。`define_tool_config!` マクロで宣言されています。

*   `enabled: bool`: サンドボックス機能が有効かどうか。
*   `allowed_directories: Vec<String>`: 読込を許可するフォルダパス（デフォルトはカレントディレクトリ `.`）。
*   `writable_directories: Vec<String>`: 書込を許可するフォルダパス。
*   `blocked_commands: Vec<String>`: 実行を禁止するシェルの正規表現リスト（例: `rm -rf /`, `sudo` 等）。
*   `max_read_bytes / max_write_bytes`: 1回のファイル入出力上限（デフォルト: 読込 50KB / 書込 1MB）。
*   `shell_timeout_ms`: 外部コマンド実行のタイムアウト（デフォルト: 120秒）。
*   `db_socket / db_auth_token`: ツールがホストのデータベースプロキシ経由でSQLite操作をするための接続ソケットと認証トークン。

### バリデーションとクリーンアップ (`sanitize()`)
*   ツールが `0` や空配列を設定してセキュリティ制限を迂回しようとするのを防ぐため、`sanitize()` メソッドにより、デフォルトの危険コマンドブロックリストの強制マージ、および `0` 値に対する安全なデフォルト床（Floor）値への自動書き換えを実施します。
