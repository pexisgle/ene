# キャラクターカードエディターガイド

デスクトップアプリには、現在選択中のキャラクターカード
（`character.json`、CCv3 形式）を編集するためのビジュアルエディターが
同梱されています。JSON を手書きしなくてもカードを安全に調整できるよう、
保存時には必ずスキーマとアセットのチェックが実行され、ファイルは
アトミックに書き込まれ、元のカードのバックアップも保持されます。

## エディターを開く

1. `ene-desktop` を起動し、`F1`（またはトレイメニュー）で設定ウィンドウを
   開きます。
2. **Character Card** タブを開きます。

エディターは **Character** タブで選択中のキャラクターのカードを読み込みます。
キャラクターを切り替えると、エディターは新しいキャラクターのカードを
再読み込みします。

## セクションの編集

カードは折りたたみ可能なセクションに分かれており、それぞれが CCv3
スキーマの一部に対応します：

| セクション | カードのフィールド |
|---|---|
| アイデンティティ | `data.name`、`data.description`、`data.creator_notes` |
| 性格 | `data.personality` |
| シナリオ | `data.scenario` |
| 挨拶 | `data.first_mes`、`data.alternate_greetings` |
| 記憶補正指示 | `data.system_prompt`、`data.post_history_instructions`、`data.mes_example` |
| ロアブック | `data.character_book.entries` |
| モーションカタログ | `extensions.ene.motion_catalog` |

ロアブックとモーションカタログのエディターでは、多くのカードで使われる
フィールド（トリガーキー、内容、有効／常時有効フラグ、正規表現／
大文字小文字オプション、挿入位置、優先度、順序、コメント、モーションの
名前・相対パス・ボディレイヤー）を編集できます。エディターが公開しない
フィールド（未知の `data` キー、アセット定義、表情定義、ロアブックの
`id`／`extensions` など）は、保存時にもそのまま保持されます。

### 多言語カードについて

エディターは常に**基本言語**のカードを編集します。キャラクターフォルダに
言語別差分（`character.{lang}.json` サイドカー）が存在する場合は通知が
表示されますが、そのファイルは変更されません。

## 保存前のバリデーション

**Validate**（検証）ボタンは、ディスクに書き込まずに組み立てたカードを
チェックします。保存時にも同じチェックが自動的に実行され、エラーが
1 件でもあると**保存はブロック**されます。各指摘は正確なフィールド位置
（例：`data.character_book.entries[0].keys`）付きで表示されるため、
どこを直せばよいかすぐに分かります。

実行されるチェック：

- 必須フィールド：`data.name`、空でない代替挨拶、ロアブックのトリガーキー
  と内容、モーションの名前とパス。最初のメッセージが空なのは CCv3 として
  合法なため、保存を妨げない警告として表示されます。
- モーションのパスはキャラクターフォルダ内に収まること（`..` や絶対パス
  は不可）。
- 宣言済みアセット（`data.assets` の VRM/VRMA）：URI が有効で、埋め込み
  ファイルがディスク上に存在すること。VRM の欠落は起動エラーにつながる
  ため保存をブロックします。リモート URL とデータ URL はローカルで
  確認できないため、保存を妨げない警告として表示されます。
- 待機モーションがカタログ内のモーションを参照していること。
- ロアブック：セカンダリキーなしのセレクティブエントリと、正規表現として
  コンパイルできないトリガーキーは警告として表示されます。

## 保存・バックアップ・破棄の保護

- **バックアップ**：セッション最初の保存時に、編集前の
  `character.json` が隣の `character.json.bak` にコピーされます。この
  バックアップは上書きされないため、何度保存しても元のカードを
  復元できます。
- **アトミック書き込み**：カードは一時ファイル＋リネームで書き込まれる
  ため、保存中のクラッシュでカードが途中までしか書き込まれないことは
  ありません。
- **破棄の確認**：未保存の変更がある状態で設定ウィンドウを閉じようとした
  場合（閉じるボタン、`Esc`、`F1`）、または **Reload**（再読み込み）を
  押した場合、さらにメインウィンドウからのアプリ終了やキャラクター切替を
  行った場合も確認ダイアログが表示されます。**破棄**で編集を破棄、
  **編集を続ける**で元の画面に戻ります。
