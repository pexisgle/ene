# ワークスペース RAG ガイド

ワークスペース RAG は、ローカルの文書やプロジェクトフォルダをインデックス化し、関連する一節を**出典付き**で会話コンテキストとして取得できるようにする機能です。これはメモリ想起・ツール選択に続く3つ目の RAG 利用者であり、同じポリシーレイヤー（`ene-rag`）を共有します: CJK 対応のハイブリッドスコアリング、見出しと行範囲のメタデータ付きチャンキング、`ene-store` に永続化されるファイルハッシュインデックスです。

## プライバシーモデル

この機能は**既定では無効で、明示的に有効化するまで何もスキャンしません**。プライバシーモデルは4層です:

1. **明示的なフォルダ許可リスト。** `rag.workspace.folders` に列挙したフォルダだけが読み取られます。スキャン前にパスを正規化し、ディレクトリシンボリックリンクは辿らず、正規化後のパスが設定フォルダの外に出るファイルはスキップします。
   ファイルシンボリックリンクは、正規化後のターゲットが設定フォルダの内側にある場合のみインデックス化されます。
2. **検索時の強制。** すべての検索（プロンプト注入と `/workspace search`）は、*現在の*設定フォルダを許可リストとして受け取ります。設定から削除したフォルダの行は次の同期で削除され、即座に検索対象から外れます。
3. **自動除外。** 既定の無視ルールは `.env` / `.env.*`、モデルデータ（`.gguf`、`.safetensors`、`.ckpt`、`.pth`、`.onnx`、`.bin`）、データベースファイル（`*.db*`）、一般的な依存／ビルドディレクトリ（`.git`、`node_modules`、`target`、`dist`、`.venv`、`assets/models`）を対象にしています。バイナリファイル（NUL バイト検出）、非 UTF-8 ファイル、`max_file_bytes`（既定 1 MiB）を超えるファイルはスキップされます。`max_chunks_per_file` を超えるファイルも、黙って切り詰めず丸ごとスキップします。
4. **ローカル永続化。** インデックス（ファイルパス、ハッシュ、チャンク本文、埋め込みベクトル）はキャラクターの `memory.db` — メモリと同じローカルデータベース — に保存されます。外部へアップロードされるものはありません。

## 設定

全キーの説明は[設定リファレンス](../ja/configuration.md#ragworkspace--ドキュメントワークスペース-rag-設定)を参照してください。プロジェクトフォルダの最小設定例:

```json
{
  "rag": {
    "workspace": {
      "enabled": true,
      "folders": ["/home/me/projects/my-app"]
    }
  }
}
```

または環境変数で:

```bash
export ENE_RAG__WORKSPACE__ENABLED=true
export ENE_RAG__WORKSPACE__FOLDERS=/home/me/projects/my-app
```

## インデックスの更新

同期はハッシュベースです。各ファイルを blake3 でハッシュし、変更・新規ファイルだけを再埋め込みします。内容が変わらないリネームは再埋め込みなしでパスを付け替え、削除されたファイルはインデックスから除去されます。同期方法は3通り:

- `sync_on_startup: true` — ランタイム起動時にバックグラウンド同期を実行。
- `/workspace sync` — バックグラウンド同期を開始。`/workspace status` で進行状況（フェーズ、スキャン・登録・スキップ数、埋め込みチャンク数）を表示、`/workspace cancel` で停止できます。キャンセルは次のファイル境界で反映され、実行中の埋め込みバッチは完了まで続行します。
- プロンプト注入と `/workspace search` は現在のインデックスを読みます。大きな編集後は同期を実行して結果を最新に保ってください。

## 出典（Citation）

取得した各チャンクは、そのソース位置（正規化されたファイルパス、直近の見出し（Markdown ATX 見出し、なければファイル名）、1始まりの行範囲）を持ちます。プロンプト注入では次のように表示されます:

```text
## Workspace Documents
- /home/me/projects/my-app/docs/setup.md:10-24 [Installation]
run cargo build --release
```

`/workspace search <query>` も同じ出典形式とハイブリッドスコアを表示します。

## プライバシーチェックリスト

- モデルと共有してもよいフォルダだけを有効化してください。
- 有効化前に `ignore_globs` を確認してください。`.env` 系は既定で除外されますが、他の拡張子に秘密情報が紛れる可能性があります。
- `folders` からフォルダを削除すると、その時点で検索対象から外れます。次の同期でインデックスからも削除されます。
- インデックスを完全に消去するには、機能を無効化してキャラクターの `memory.db` を削除するか（メモリも消えます）、`folders` を空にして同期を実行してください（空の許可リストは全行を削除します）。

## 未対応（今後）

- RAG 設定のデスクトップ設定 UI（現状は JSON／環境変数のみ）。
- ファイル監視による自動同期（手動または起動時のみ）。
- 非 UTF-8・バイナリ文書は変換せずスキップ。
