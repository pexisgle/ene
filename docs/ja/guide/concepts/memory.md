# 記憶

ene はセッションをまたいで **長期記憶** を保持できます。事実、エピソード、好み、コミットメントなどを SQLite に保存し、必要に応じてベクトル検索も利用できます。

## 役割分担

| 層 | 責任 |
|----|------|
| **mind** | 想起の計画、重要度の評価、ターン後の書き込み、忘却ポリシー |
| **store** | テキスト（と任意の埋め込み）の永続化、フィルタ付き検索 |

永続化は `store.enabled` と、必要に応じて `store.db_path` で設定します。想起と減衰に関する設定は `mind.*` にあります。

## ハイブリッド想起（考え方）

埋め込み、字句一致、新しさ、顕著性などを組み合わせられます。mind が検索全体を調整し、store が検索処理を実行します。
