# セッション

**セッション**はキャラクターごとの会話コンテキストです。履歴、カード由来のアイデンティティ、いつ分割・圧縮するかを含みます。

## セッションを形作るもの

- キャラクターカード（`CharacterCardV3`）とマクロ（CBS 風の展開）
- 作業コンテキストに残る直近メッセージ
- 圧縮・分割に関する mind ポリシー（タイムアウト、話題変化、手動分割）

## 分割

長い・話題が変わった会話は新しいセッションを始めつつ、記憶と要約で連続性を保ちます。トリガーはアイドルタイムアウト、話題変化検出、診断からの明示的 / 手動分割です。
