# セッション

**セッション**はキャラクターごとの会話コンテキストです。履歴、キャラクターカードで定義された設定、分割・圧縮のタイミングを含みます。

## セッションを形作るもの

- キャラクターカード（`CharacterCardV3`）とマクロ（CBS 風の展開）
- 現在のコンテキストに保持される直近のメッセージ
- 圧縮・分割に関する mind ポリシー（タイムアウト、話題変化、手動分割）

## 分割

会話が長くなった場合や話題が変わった場合は、新しいセッションを開始します。その際も、記憶と要約によって会話の連続性を保ちます。トリガーはアイドルタイムアウト、話題変化検出、診断からの明示的な分割、手動分割です。
