# 記憶台帳：インタラクティブな記憶・コミットメント管理

記憶台帳（Memory Ledger）は、コンパニオンの長期記憶とコミットメント台帳をGUIから確認・管理するためのデスクトップ設定ページです。エピソード記憶、セマンティック記憶、ユーザープロフィール、関係性、感情記憶、コミットメント、嗜好、手順、世界状態、内省など、保存されたすべての記憶項目と、あらゆるライフサイクル状態のコミットメントを表示します。

**設定 → 記憶台帳**（*記憶* の隣のタブ）から開きます。

## 検索とフィルター

ツールバーには次の操作があります：

- **検索** — 記憶のタイトルと内容に対するフリーテキスト一致。
- **種類** — 記憶カテゴリ（種類がカテゴリタグの役割を果たします）による絞り込み。
- **ステータス** — ライフサイクル状態（アクティブ、減衰、アーカイブ済み、論争中、置換済み、削除済み）による絞り込み。
- **作成日** — 直近 7 / 30 / 90 日以内に作成された記憶、またはすべて。

テーブルの上には、読み込み済みの行の種類別分布を示す *種類別の記憶数* バーが表示されます。

## 記憶の管理

各行には、種類、タイトル、内容プレビュー、作成日、ステータス、スコープ、およびインラインスライダー付きの重要度バーが表示されます：

- **重要度スライダー** — 記憶の salience スコア（ハイブリッド想起での競争力）を調整します。嗜好（Preference）記憶では、同じコントロールが *嗜好ウェイト* と表示されます。
- **編集** — タイトル、内容、種類、信頼度を変更するダイアログを開きます。編集時には種類から所有スコープが再導出され（例：*嗜好* に変更するとユーザースコープになります）、ベクター想起が正確なままになるよう埋め込みもバックグラウンドで更新されます。
- **削除** — 記憶を削除済みとしてマークします（*削除を確定* が必要）。削除された記憶は想起から除外されます。記憶ジャーナルページから復元できます。

## コミットメントの管理

コミットメントのテーブルには、あらゆるステータス（アクティブ、完了、キャンセル済み、期限切れ）のコミットメントが、期限日と作成日とともに表示されます。アクティブなコミットメントには **完了** と **キャンセル** ボタンがあり、ステータスの変更は台帳とプロンプト注入の両方に即座に反映されます。

## 備考

- 台帳にはメモリストア（`store.enabled = true`）が必要です。無効な場合は更新時にエラーが表示されます。
- 変更操作はランタイムのアクターメールボックスを経由し、ライフサイクルバスに `MemoryLedgerChanged` 監査イベントを発行するため、外部コンシューマー（CLI、API v1）も手動編集と重要度調整を観測できます。
