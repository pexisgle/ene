# Git ツールガイド

`ene-plugin-git` は読み取り専用の Git リポジトリ検査ツールを提供します:
ワーキングツリーの状態、差分、コミット履歴、ブランチ一覧、リモート設定、
行単位の責務追跡 (blame) です。組み込みツールプラグインであり、新規
インストール時に自動的に起動します。

すべてのアクションは厳密に読み取り専用です — commit・push・pull・fetch・
clone はありません。各アクションは構造化 JSON を返します。

## アクション

| アクション | 用途 |
|---|---|
| `git.status` | 現在のブランチ (または detached HEAD) と、ファイルごとの staged / unstaged / untracked / 競合状態 |
| `git.diff` | 未ステージまたはステージ済み変更の unified diff テキスト・統計サマリー |
| `git.log` | 作者・タイムスタンプ・親コミット付きのコミット履歴 |
| `git.branch` | ローカル (任意でリモート追跡) ブランチと、上流ブランチ・先行/遅延数 |
| `git.remote` | フェッチ・プッシュ URL 付きの設定済みリモート |
| `git.blame` | コミット済みファイルの行単位の責務追跡 |

## リポジトリパスとワークスペースサンドボックス

各アクションは省略可能な `path` 引数を持ち、既定はカレントディレクトリ
です。パスは解決・正規化され、ワークスペースの許可ディレクトリのいずれか
の内側にある必要があります — ファイルシステムプラグインと同じサンドボック
ス契約です。そのパスから発見されたリポジトリのワーキングツリーも許可領域
の内側にある必要があるため、ワークスペース内のパスを使ってワークスペース
外にある祖先リポジトリの履歴を読むことはできません。

リポジトリ相対のファイル引数 (`git.diff` の `pathFilter`、`git.blame` の
`file`) は検証されます: 相対パスのみ、`..` セグメントなし、絶対パスなし。

## 使用例

現在のリポジトリの状態を確認:

```json
{"path": "."}
```

特定パスのリポジトリでステージ済み差分を統計付きで取得:

```json
{"path": "/home/me/project", "staged": true, "format": "both"}
```

直近 10 コミット:

```json
{"path": ".", "maxCount": 10}
```

`src/main.rs` の 1〜5 行目を blame:

```json
{"path": ".", "file": "src/main.rs", "startLine": 1, "endLine": 5}
```

## 補足

- `git.diff` は既定 (`staged: false`) でワーキングツリーとインデックスを、
  `staged: true` でインデックスと HEAD を比較します。差分が空の場合は
  エラーではなく変更ゼロの出力を返します。
- `git.log` は既定で HEAD から辿ります。`branch` を渡すと別のブランチや
  ref から辿ります。`maxCount` は最大 100 です。
- `git.blame` はコミット済み HEAD バージョンを対象とします。未コミットの
  ワーキングツリー編集は反映されません。
- タイムスタンプはコミットの元のタイムゾーンオフセットを保持した RFC 3339
  文字列です。
- 設定は不要です。このプラグインは既定で有効
  (`settings.json` の `tools.list.git.enable = true`) であり、他のツール
  プラグインと同様に無効化できます。
