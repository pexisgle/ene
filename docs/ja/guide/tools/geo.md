# 地理情報ツールガイド

`ene-plugin-geo` は、IP ベースの位置情報・現在の天気・太陽時 UTC オフセット
計算・日の出日の入り時刻を提供する地理情報ツールです。組み込みツール
プラグインとして新規インストール時に自動的に起動します。

## アクション

### `geo.location`

[ip-api.com](https://ip-api.com/) を使って IP アドレスのおおよその位置
（国・地域・都市・座標・タイムゾーン）を取得します。

```json
{"ip": "8.8.8.8"}
```

`ip` を省略すると、呼び出し元自身のパブリック IP を特定します:

```json
{}
```

呼び出し元 IP の特定はユーザーのおおよその位置を明かすため、明示的な
ユーザー承認が必要です。承認はターン単位で失効します。「このセッション
では許可」を選ぶと、その会話の間は許可が維持されます。

### `geo.weather`

[wttr.in](https://wttr.in/) から現在の天気（気温・湿度・雲量・風・視程・
気圧）を取得します。`location` は都市名または `lat,lon` 座標です:

```json
{"location": "Tokyo"}
```

```json
{"location": "35.68,139.69"}
```

`location` を省略すると、wttr.in は呼び出し元の IP アドレスから位置を
推定します。`geo.location` と同様に、この呼び出しはユーザーのおおよその
位置を明かすため、明示的なユーザー承認が必要です。

### `geo.timezone`

経度から理論上の太陽時 UTC オフセットを計算します（経度 15 度 = 1 時間）。
外部 API は使いません:

```json
{"longitude": 139.68}
```

結果は太陽時のオフセットであり、実際のタイムゾーンとは異なる場合が
あります（国境による境界や夏時間は反映されません）。

### `geo.sunrise_sunset`

[sunrise-sunset.org](https://sunrise-sunset.org/) から座標に応じた日の出・
日の入り・正中・昼の長さ・薄明時刻を取得します。任意の `date`
（`YYYY-MM-DD`、既定は UTC 基準の今日）と IANA タイムゾーン名
（既定は `UTC`）で、基準日と返されるタイムスタンプのオフセットを
指定できます:

```json
{"latitude": 35.68, "longitude": 139.69, "date": "2026-08-04", "tzid": "Asia/Tokyo"}
```

## プライバシーとネットワークに関する注意

- `geo.location` と IP 由来の `geo.weather` は、ユーザーのパブリック IP を
  第三者サービスへ送信し、おおよその位置を明かします。どちらも Ene の
  書き込み操作と同じターン単位の承認メカニズムで保護されています。
- ip-api.com の無料枠は平文 HTTP のみ対応のため、`geo.location` の
  リクエスト自体は暗号化されません（IP はマシンが通信するどの HTTP
  エンドポイントにも見える情報ですが、通信経路上にも見える点に注意して
  ください）。
- すべての HTTP 呼び出しは 10 秒のタイムアウト、レスポンス本文は 1 MiB
  上限です。出力は固定フィールドのみで、結果は常に小さく保たれます。
- `geo.timezone` はマシンの外へ一切通信しません。

## 設定

設定は不要です。プラグインは既定で有効
（`settings.json` の `tools.list.geo.enable = true`）で、他のツール
プラグインと同様に無効化できます。
