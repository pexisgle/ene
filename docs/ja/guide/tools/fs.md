# ファイルシステムツール (`ene-tool-fs`)

**バイナリ:** `ene-tool-fs` | **ステートフル:** はい (Sandbox + UndoManager、DB IPC 経由)

ファイルシステム操作、シェル実行、および Undo を提供します。すべてのファイル操作はサンドボックス設定を尊重します。

## ツール (Tools)

### `filesystem.read`

ファイル内容の読み取り、またはディレクトリ内のファイル一覧の取得。

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|----------|-------------|
| `filePath` | string | はい | ファイルまたはディレクトリへの絶対パス |
| `offset` | integer | いいえ | 読み取りを開始する行番号 (1始まり) |
| `limit` | integer | いいえ | 読み取る最大行数 |

**制限:** 最大読み取りサイズは 50KB。

---

### `filesystem.write`

ファイルの書き込みまたは作成。

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|----------|-------------|
| `filePath` | string | はい | ファイルへの絶対パス |
| `content` | string | はい | 書き込む内容 |

**制限:** 最大書き込みサイズは 1MB。親ディレクトリは自動的に作成されます。Undo 用のバックアップが作成されます。

---

### `filesystem.edit`

9 つのマッチング戦略による、ターゲットを絞ったテキスト置換。

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|----------|-------------|
| `filePath` | string | はい | ファイルへの絶対パス |
| `oldString` | string | はい | 置換対象のテキスト |
| `newString` | string | はい | 置換後のテキスト |
| `replaceAll` | boolean | いいえ | すべての一致箇所を置換する (デフォルト: false) |

**マッチング戦略** (以下の順に適用されます):
1. `trimmed_boundary` — 境界の空白をトリム
2. `simple` — 完全一致
3. `whitespace_normalized` — 空白の違いを吸収
4. `escape_normalized` — エスケープシーケンスを正規化
5. `line_trimmed` — 各行の空白をトリム
6. `multi_occurrence` — 複数出現を処理
7. `indentation_flexible` — インデントの違いを無視
8. `context_aware` — 周辺コンテキストでマッチ
9. `block_anchor` — コードブロック検出でアンカリング

---

### `filesystem.delete`

ファイルまたはディレクトリの削除。

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|----------|-------------|
| `path` | string | はい | ファイルまたはディレクトリへの絶対パス |
| `recursive` | boolean | いいえ | ディレクトリを再帰的に削除する |

---

### `filesystem.glob`

パターンベースのファイル検索。

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|----------|-------------|
| `pattern` | string | はい | Glob パターン (例: `**/*.rs`) |
| `path` | string | いいえ | 検索対象のディレクトリ (デフォルトはカレントディレクトリ) |

---

### `filesystem.grep`

コンテンツベースの正規表現検索。

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|----------|-------------|
| `pattern` | string | はい | 検索する正規表現パターン |
| `path` | string | いいえ | 検索対象のディレクトリ |
| `include` | string | いいえ | ファイルパターンのフィルタ (例: `*.rs`) |

---

### `filesystem.patch`

Unified diff パッチの適用。

| パラメータ | 型 | 必須 | 説明 |
|-----------|------|----------|-------------|
| `patchText` | string | はい | Unified diff パッチの全文 |

**動作:** 複数ファイルへのパッチは、単一の Undo エントリとしてグループ化されます。

---

### `shell.execute`

セキュリティ制限付きでのシェルコマンドの実行。

| パラメータ | 型 | 必須 | デフォルト | 説明 |
|-----------|------|----------|---------|-------------|
| `command` | string | はい | — | 実行するシェルコマンド |
| `description` | string | はい | — | コマンドの動作を説明する 5〜10 単語の文字列 |
| `timeout` | integer | いいえ | 120000 | タイムアウト (ミリ秒) |
| `workdir` | string | いいえ | カレント | 作業ディレクトリ |

**セキュリティ:** 実行コマンドは `blocked_commands` パターンと照合されます。出力は 50KB / 2000 行に制限されます。

---

### `utility.undo`

直前のファイル操作を取り消します。

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| (なし) | — | — |

**動作:** write, edit, delete, patch 操作を取り消します。シェル操作は取り消しできません。Undo スタックは、zlib 圧縮された状態で、ツールごとの DB IPC サーバーを介して永続化されます。

## カテゴリ (Category)

すべてのファイルシステムツール: `Filesystem` | シェル: `Shell` | Undo: `Utility`

## サンドボックス統合 (Sandbox Integration)

すべてのファイル操作は `Sandbox::check_readable()` または `Sandbox::check_writable()` を通過します：

```
リクエスト → Sandbox 有効?
  ├── いいえ → 直接実行
  └── はい
       ├── パス正規化
       ├── ディレクトリ許可リスト確認 → 許可外なら拒否
       ├── シェル: blocked_commands パターン確認 → 一致なら拒否
       └── サイズ/出力制限付きで実行
```
