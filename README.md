# ene

ene（エネ）は、ユーザー自身が管理するPC（ホスト）上で動作する、**AIパートナー（Companion）** を中心としたパーソナルAIシステムです。

日常的な会話を楽しみながら、ファイル整理や調べ物といったPC上の実際の作業も同じパートナーに任せられます。対話の記憶や各種設定など、大切なデータの大元（マスター）はすべて自分のPC上で安全に管理されます。
